### Oferta inicial propuesta

Una web de presentación adaptable a celular, con servicios, fotos, horarios y
contacto por WhatsApp. Dominio y hosting a nombre y cargo del cliente. Alcance,
correcciones, precio y forma de pago acordados antes de empezar.

Las aplicaciones existentes requieren evaluación antes del presupuesto. Tiendas,
pagos y funciones a medida no se incluyen automáticamente en el servicio inicial.
El mantenimiento tiene tareas definidas; los nuevos desarrollos se cotizan aparte.

Esta es una propuesta de trabajo, no una tarifa ni un contrato ya aprobado.

### Qué falta demostrar

No hay clientes ni ingresos de este servicio registrados en esta conversación.
Tampoco hay tiempos medidos de entrega, margen comprobado ni precio de venta.
La viabilidad técnica no demuestra demanda ni rentabilidad.

### Primer experimento comercial

Identificar un negocio cercano con una necesidad concreta de presencia web.
Entender cómo recibe consultas hoy y qué resultado quiere mejorar. Si el problema
encaja, ofrecer un trabajo pago con alcance pequeño y registrar horas, gastos,
cambios pedidos y resultado de la entrega.

El criterio de éxito inicial es vender, entregar y conocer el margen de un caso.
No se necesita una plataforma de autoservicio para comprobarlo.

### Infraestructura

Contabo es el candidato conversado, no una compra realizada. Antes de contratar:
confirmar total mensual, región, alta, condiciones y acceso de recuperación.
La web actual es estática; no necesita backend ni base de datos.

La plataforma futura se reconsidera cuando aparezcan tareas repetidas entre
clientes que justifiquen automatizarlas.
